# [Homebrew](https://brew.sh)
*[Homebrew Manpage (detailed documenation)](https://docs.brew.sh/Manpage)*

Homebrew is the easiest, most flexible way to install the UNIX tools Apple didn’t include with macOS.
It can also install software not packaged for your Linux distribution without requiring sudo.

## What Does Homebrew Do?

- Homebrew installs the stuff you need that Apple (or your Linux system) didn’t.
- Homebrew installs packages to their own directory and then symlinks their files into /opt/homebrew (on Apple Silicon).
- Homebrew won’t install files outside its prefix and you can place a Homebrew installation wherever you like.
- Homebrew complements macOS (or your Linux system). Install your RubyGems with gem and their dependencies with brew.
- “To install, drag this icon…” no more. Homebrew Cask installs macOS apps, fonts and plugins and other non-open source software.
